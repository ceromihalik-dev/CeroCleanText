# CeroCleanText

Lightweight Windows tool for cleaning selected text from hidden Unicode characters, unwanted formatting and special whitespace. Fast, private and resource-efficient.

## Current development status

CeroCleanText 0.1.0 is currently under development. The Windows tray application can clean selected text via a global hotkey or tray command. Text processing is performed locally.

## Privacy

CeroCleanText does not need to upload the selected text to a server for cleaning. The cleaning engine runs locally on the Windows computer.
